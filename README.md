# CodeSnippets

This repository contains a collection of reusable code snippets using Google DeepMind Gemini Models.

## Project Structure

```{project/}
 ├── snippets/ 
 │   └── gemini_rag.py 
 ├── docs/ 
 │   ├── gemini_rag.Rmd
 │   └── gemini_context_url.Rmd
 └── README.md
 ```

-   `snippets/`: code snippets using Python.
-   `docs/`: Additional documentation.
-   `README.md`: Info about this project

## Purpose

This repository aims to centralize useful code snippets, promote clean coding practices and make sharing between teams easier.

## Supported Languages

-   Python
